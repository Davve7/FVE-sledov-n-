Výroba FVE, dokup ze sítě, elektroměr (VT/NT) a nabíjení auta

Týdenní odečet FVE

Každou neděli večer zadej aktuální stavy čítačů FVE: výrobu a dokup ze sítě. Roční přírůstky se počítají samostatně; na začátku nového roku začíná evidence FVE od nuly.

Čísla vlevo jsou ISO týdny (pondělí–neděle).
Vybraný týden: –

Použije se pro orientační výpočet hodnoty vyrobené elektřiny. Cena VT a NT se nastavuje samostatně u měsíčního odečtu elektroměru.

Touto cenou se počítají náklady na dokup. Když pole nevyplníte, použije se cena elektřiny nahoře.

Měsíční odečet elektroměru

Zadávej aktuální stavy VT a NT poslední den v měsíci. Stavy pokračují mezi roky. U prvního záznamu vyplň počáteční stav z počátku sledovaného měsíce, aby se omylem nezapočítala historická spotřeba.

Čísla vlevo jsou ISO týdny (pondělí–neděle).

Zadej konečné stavy starého elektroměru a počáteční stavy nového. Spotřeba se sečte z obou zařízení.

Vyfotit / načíst elektroměr

Vyber fotku nebo pořiď snímek displeje. OCR se pokusí rozpoznat čísla; výsledek vždy zkontroluj.

Fotku můžeš načíst po výběru souboru.

Vyber kandidáta, který odpovídá číselníku. OCR může zachytit i výrobní číslo.

    Synchronizace a záloha dat

    Automatická synchronizace mezi zařízeními: přihlaste se stejným účtem Firebase na každém zařízení. Dosavadní záznamy z tohoto prohlížeče zůstanou zachované a při prvním přihlášení se sloučí s cloudovými.

    Cloudová synchronizace (volitelně)

    URL najdete v nastavení Realtime Database, Web API klíč v nastavení projektu Firebase → Vaše aplikace. Klíč Web API je identifikátor aplikace; přístup k datům chrání přihlášení a pravidla níže. Zapněte metodu E‑mail/heslo v Authentication.

    Bezpečná pravidla Firebase Realtime Database

    V Authentication zapněte poskytovatele E‑mail/heslo. V Realtime Database → Pravidla nahraďte pravidla následujícím JSONem. Každý účet pak může číst a měnit jen vlastní záznamy podle jedinečného Firebase UID:

    {
  "rules": {
    "users": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid"
      }
    },
    "shelly": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid",
        "$ts": {
          ".write": "!data.exists()",
          ".validate": "$ts.matches(/^[0-9]{10}$/) && newData.hasChildren(['imp','exp'])",
          "imp": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() < 1000000000000" },
          "exp": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() < 1000000000000" },
          "$other": { ".validate": false }
        }
      }
    }
  }
}

    Část „shelly“ je potřeba jen pro automatický odečet z Shelly Pro 3EM (viz níže). Dovoluje bez přihlášení jen přidat nový odečet na cestu s vaším UID; číst, měnit nebo mazat může jen přihlášený vlastník.

    Účty vytvořené přes tlačítko výše jsou samostatné; na všech svých zařízeních použijte stejný e‑mail a heslo.

    Automatický odečet ze Shelly Pro 3EM

    Shelly Pro 3EM každý den v 0:00 pošle stav čítačů (odebraná a dodaná energie) do vašeho Firebase. Aplikace si je načte sama a spočítá denní odběr a přetok.

    1. V pravidlech Firebase (výše) mějte i část „shelly“.
    2. Přihlaste se tlačítkem „Přihlásit“. Do skriptu se tím doplní adresa databáze a vaše UID.
    3. Ve webovém rozhraní Shelly otevřete Scripts → Add script, vložte skript níže, uložte ho, zapněte „Run on startup“ a spusťte ho.
    4. Hned po spuštění pošle jeden zkušební odečet. Zobrazí se po stisknutí „Načíst odečty ze Shelly“. Dál se odečet posílá každý den v 0:00 místního času zařízení (zkontrolujte časové pásmo v nastavení Shelly: Europe/Prague).
